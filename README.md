# Covai Scrap Hub ♻️

## Overview

**Covai Scrap Hub** is a web-based scrap management and collection platform designed to connect customers with scrap collectors through a simple and convenient digital solution.

The platform enables customers to check current scrap rates, sell recyclable materials, book doorstep pickups, and track their pickup requests online. It also provides dedicated **Admin** and **Partner** panels to manage and coordinate scrap collection operations efficiently.

## Live Website

🌐 **Live Demo:** https://covaiscraphup.vercel.app/

---

## Key Features

### Customer

- Check current scrap rates
- View available scrap materials
- Submit scrap-selling requests
- Book doorstep pickup
- Track pickup requests
- View request status
- Tamil and English language support
- Responsive design for mobile and desktop

### Admin Panel

- Manage customer requests
- Manage scrap materials
- Update scrap rates
- Manage pickup requests
- Manage partners
- Monitor collection activities

### Partner Panel

- View assigned pickup requests
- Manage pickup activities
- Update pickup status
- Track customer requests
- Manage collection status
